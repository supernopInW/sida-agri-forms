📤 นำเข้าไฟล์ Excel (.xlsx) เพื่ออัปเดตข้อมูล

รองรับไฟล์ Excel (.xlsx / .xls) ทั้งแบบ ทั้งอำเภอ (หลายชีต รม.) และแบบ รายหมู่บ้าน (1 ชีต รม.) ที่ดาวน์โหลดจากระบบนี้หรือไฟล์แบบฟอร์มราชการ ระบบจะอัปเดต รม. → รต. → รอ. และแดชบอร์ดให้อัตโนมัติ
📑
คลิกเลือกไฟล์ Excel (.xlsx / .xls) หรือลากไฟล์มาวางที่นี่
ระบบจะอ่านและแสดงสรุปข้อมูลให้ตรวจสอบก่อนบันทึกจริง

สำรองและกู้คืนข้อมูล

ข้อมูลที่แก้ไขจะถูกบันทึกอัตโนมัติในเบราว์เซอร์เครื่องนี้ คุณสามารถส่งออกไฟล์ JSON เพื่อนำไปเปิดเครื่องอื่น หรือรีเซ็ตกลับไปใช้ข้อมูลตั้งต้นจากไฟล์ Excel ได้
