# ระบบจัดเก็บข้อมูลการผลิตทางการเกษตรด้านพืช อำเภอสีดา จังหวัดนครราชสีมา (รอ. / รต. / รม.)

เว็บแอปพลิเคชันสำหรับจัดเก็บ เพิ่ม ลบ แก้ไข และสรุปข้อมูลการผลิตทางการเกษตรด้านพืช อำเภอสีดา จังหวัดนครราชสีมา ครบทั้ง **5 ตำบล 50 หมู่บ้าน** เชื่อมโยงยอดรวมอัตโนมัติจาก **แบบ รม. (รายหมู่บ้าน) → แบบ รต. (รายตำบล) → แบบ รอ. (รายอำเภอ)**

## รหัสผ่านเข้าใช้งาน
- รหัสผ่านเริ่มต้น: `123456`

## ฟีเจอร์หลัก
- **เชื่อมโยงข้อมูลอัตโนมัติ (รม. → รต. → รอ.)**: เมื่อเพิ่ม แก้ไข หรือลบแปลงเกษตรกรในแบบ รม. ยอดรวมครัวเรือน พื้นที่การเกษตร พื้นที่ปลูกใหม่/ยืนต้น/เก็บเกี่ยว และผลผลิตรวมในแบบ รต. และ รอ. จะอัปเดตทันที
- **เพิ่ม / ลบ / แก้ไขสะดวก**: รองรับการค้นหาชื่อเกษตรกร เลขเอกสารสิทธิ์ กรองตามชนิดพืช และกด `+แปลง` เพื่อเพิ่มแปลงต่อจากเกษตรกรรายเดิมได้ทันที
- **รองรับครบทั้ง 10 ชนิดพืช**: ข้าว (มะลิ 105), ข้าวโพดเลี้ยงสัตว์, มันสำปะหลัง (เกษตรศาสตร์ 80 พร้อมแยกไม่เก็บ/เก็บท่อนพันธุ์), อ้อยโรงงาน (ขอนแก่น 3), ทุเรียน, กล้วยหอมทอง, มะม่วง, ละมุด, น้อยหน่า และอื่นๆ/กล้วยน้ำว้า
- **ส่งออกตรงตามแบบฟอร์ม**:
  - ดาวน์โหลดเป็น **Excel (.xlsx)** แยกแบบ รอ. / รต. / รม. หรือดาวน์โหลดทั้งเล่ม 56 ชีตในคลิกเดียว
  - **สั่งพิมพ์ / บันทึกเป็น PDF** แนวนอน (A4 Landscape) พร้อมหัวฟอร์มราชการและช่องลงชื่อ
- **สำรองและกู้คืนข้อมูล**: บันทึกอัตโนมัติลงเบราว์เซอร์ (`localStorage`) พร้อมปุ่ม Export/Import ไฟล์สำรอง `.json`
